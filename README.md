# Product-Price-Tracker---Web-Scraping-with-Python

This project is an advanced web scraper built in Python that extracts real-time product data (title, price, and stock availability) from an e-commerce website and saves the data into an Excel file. It is designed for users who want to track prices or monitor product availability over time. The project can be further expanded to monitor price changes, send alerts, or store data in a database.

It is ideal for:

Freelancers & automation experts who offer data scraping services

Students learning BeautifulSoup and pandas

Business owners who want to watch competitors’ prices
